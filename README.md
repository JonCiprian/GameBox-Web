# GameBox – Página web

Este repositorio forma parte del proyecto GameBox y se utilizará para guardar todo lo relacionado con el desarrollo de su página web, una tienda online de productos y accesorios gaming.

En él se irán subiendo los archivos y las modificaciones que se realicen durante la creación de la web. También servirá para tener el trabajo organizado, consultar los cambios que se han ido haciendo y ver cómo avanza el desarrollo de la página desde el principio hasta su versión final.
